이 패치는 게임의 원본 파일을 직접 수정하지 않고, 지원되는 모드 적용 환경에서 수정된 파일을 불러오는 방식으로 동작합니다.

## 준비 사항

닌텐도 스위치 커펌 or 에뮬레이터

Build ID : 01005880134C2000

Title ID : C8A3A29B0BBEAE47

Version : 1.3.0

> [!WARNING]
> **일본판 버전이 아니라 USA버전 입니다.**

게임 버전에 따라 패치가 정상적으로 동작하지 않을 수 있으므로, 설치 전에 호환 버전을 확인해 주세요.

## 설치 방법

에뮬레이터 기준으로 설명합니다.

위의 다운로드 링크에서 최신 버전의 Shadowverse-KR-Patch-v1.0.0.zip을 다운로드합니다.

ZIP 파일의 압축을 풉니다.

에뮬레이터에서 모드 폴더 열기 혹은

C:\Users\사용자이름\AppData\Roaming\에뮬레이터 이름\load\01005880134C2000

이곳으로 들어가주세요 01005880134C2000폴더가 없다면 생성하시면 됩니다.

이곳에 압축을 풀어서 나온 romfs폴더를 넣으면 됩니다.

\01005880134C2000
└─ romfs\
   └─ Data\
      └─ StreamingAssets\
         └─ lang_font_en, lang_gametext_battle_en, lang_gametext_resident_en, resident_font
		 
이렇게 들어가 있으면 된겁니다.

다음 에뮬레이터에서 해당 게임 우클릭 -> 속성 혹은 모드 적용 -> KR-Patch 체크 후 게임실행

## 업데이트 방법

최신 버전의 패치 ZIP을 다운로드합니다.

기존 패치에서 설치한 파일을 새 버전으로 교체합니다.

이전 버전에서 사용하지 않게 된 파일이 있다면 해당 파일도 정리합니다.

##제거 방법

패치 설치 시 추가한 폴더만 제거하면 됩니다.
